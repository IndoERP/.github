# Contributing to IndoERP projects

Thank you for helping. Contributions of every size are welcome: code, tests, documentation, translations, bug
reports and ideas.

- The main project is [ERPForAll](https://github.com/IndoERP/ERPForAll). Its
  [CONTRIBUTING.md](https://github.com/IndoERP/ERPForAll/blob/main/CONTRIBUTING.md) covers the licence of
  contributions, the sign-off and how to build and test; a repository without a guide of its own follows the same
  rules.
- All projects here are licensed MIT OR Apache-2.0. Unless you state otherwise, a contribution is licensed under
  the same terms.
- Sign off every commit (`git commit -s`, the [Developer Certificate of Origin](https://developercertificate.org/)).
- Not sure where to start? Ask in [Discussions](https://github.com/IndoERP/ERPForAll/discussions).
- Security problems are reported privately: see [SECURITY.md](SECURITY.md).
