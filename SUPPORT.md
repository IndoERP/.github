# Getting help

- **Questions and how-to:** ask in [Discussions, Q&A](https://github.com/IndoERP/ERPForAll/discussions/categories/q-a).
- **Ideas and design proposals:** [Discussions, Ideas](https://github.com/IndoERP/ERPForAll/discussions/categories/ideas).
  A proposal that changes how addons or the core work is easier to discuss there before any code is written.
- **Bugs:** open an [issue](https://github.com/IndoERP/ERPForAll/issues/new/choose) with the steps to see the problem.
- **Security problems:** never in public. See [SECURITY.md](SECURITY.md).
- **Documentation:** [indoerp.github.io/ERPForAll](https://indoerp.github.io/ERPForAll/).

The project is in early development and maintained by a small team; answers can take a few days.
