# Security policy

Please do not open a public issue for a security problem. Open the repository concerned, go to its Security tab and
choose "Report a vulnerability" (GitHub private vulnerability reporting). Include a description, the affected
version or commit, and steps to reproduce.

We will acknowledge a report and keep you informed of the fix. Please give us reasonable time to release a fix
before you disclose details publicly.

The main repository's own policy is in
[ERPForAll/SECURITY.md](https://github.com/IndoERP/ERPForAll/blob/main/SECURITY.md).
